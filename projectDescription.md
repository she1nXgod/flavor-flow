# Разработка веб-приложения для поиска рецептов

## 1. Актуальность темы

В современном ритме жизни процесс планирования рациона и поиска подходящих блюд часто отнимает много времени. Существующие кулинарные порталы перегружены рекламой, избыточной информацией и сложной навигацией.

Разработка минималистичного и интуитивно понятного веб-приложения, позволяющего быстро находить рецепты по категориям, оценивать время приготовления и сохранять понравившиеся варианты в личный профиль, является актуальной задачей. Это решает проблему структуризации кулинарного контента и улучшает пользовательский опыт за счет современного UI/UX дизайна.

## 2. Целевая аудитория

- **Люди, предпочитающие готовить дома**, но имеющие ограниченное время на поиск рецептов.
- **Начинающие кулинары**, которым важна четкая структура (ингредиенты, шаги, уровень сложности).
- **Пользователи, желающие систематизировать** свои любимые блюда в едином цифровом пространстве.

## 3. Предполагаемые функциональные возможности

- **Система авторизации:** Вход в систему (Login) для разделения гостевого и пользовательского доступа.
- **Каталог рецептов:** Отображение списка доступных блюд в виде карточек.
- **Фильтрация и навигация:** Сортировка рецептов по категориям (Завтраки, Обеды, Ужины, Пицца, Десерты).
- **Детальный просмотр:** Страница конкретного рецепта с указанием времени приготовления, сложности, количества порций, списка ингредиентов и пошаговой инструкции.
- **Система избранного:** Возможность отмечать рецепты лайком (сохранять в «Избранное») для быстрого доступа в будущем.

## 4. Используемые технологии

- React, TypeScript, React Bootstrap

## 5. Ожидаемый результат

Готовое Fullstack веб-приложение с адаптивным пользовательским интерфейсом. Пользователь сможет зарегистрироваться, войти в систему, просматривать каталог блюд, использовать фильтры по категориям и формировать собственный список любимых рецептов. Проект будет обладать масштабируемой архитектурой, готовой к дальнейшему расширению функционала.
